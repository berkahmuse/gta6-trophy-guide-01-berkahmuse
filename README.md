**Leonida Ledger.** The GTA VI trophy list (PlayStation 5) kept as a book of accounts: a ruled ledger table with one line per trophy — official name, official description, grade, a counter where PlayStation counts, and the Ledger's own note on how to settle the line, with its reference (the official list on Exophase and PSNProfiles) printed under every note. The sidebar keeps the balance (settled count, missables still open), the six-stage order of the book that serves as the roadmap to the platinum, and the nine missable lines flagged from the official descriptions. The book is stored in localStorage and can be exported to a file and imported back; kind and grade filters and search keep the table short; a spoiler rule seals the name and description of unearned story lines. Original ledger design; no Rockstar artwork or logos.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or serve app/ with any static HTTP server and open index.html
```

To hand the entry in (writes the dossier to `out/`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no build step, no network at run time.
